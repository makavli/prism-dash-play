# Play PRISM DASH

**▶ [makavli.github.io/prism-dash-play](https://makavli.github.io/prism-dash-play/)**

A neon arena game where your dash is your only weapon. It runs in your browser with nothing to install.

This repository holds only the browser build. It is published automatically from the game's private repository whenever a new version is tagged; do not edit it by hand.
